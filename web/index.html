Connect to a computer

Host a session

Run the Host app on the computer you want to access.

The host agent connects outbound to your relay server, creates a short-lived PIN, and asks the person at the computer to approve each connection.
Security note: A 3-digit PIN has only 1,000 combinations. This design expires PINs after 2 minutes, limits failed attempts, allows one controller at a time, and requires host approval. Deploy behind HTTPS/WSS. Do not expose a host agent to unknown users.
